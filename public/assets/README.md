# Portfolio assets

- `home/` contains the home page hero and profile images.
- `backgrounds/` contains the category and section backgrounds.
- `project-previews/` contains project card, wireframe, and final design images.
- `social-media/posts/` contains the supplied social media images and PDF documents.

The website and admin page reference these files through `/assets/...` paths. Keep filenames unchanged when replacing an asset, or update the matching path in `src/pages/Home.tsx`, `src/pages/ProjectsPage.tsx`, or `src/pages/AdminPage.tsx`.
